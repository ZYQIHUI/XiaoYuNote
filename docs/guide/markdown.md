# Markdown 渲染

笔记本编辑器保存 Markdown 原文，预览区域将同一份原文转换为可阅读的文档显示。编辑区和预览区使用同一当前内容，保存后内容写入当前日报、周报或月报文件。

## 编辑区

编辑区支持普通文本输入、撤销、重做、剪贴板粘贴和图片插入。Markdown 源码保持原样保存，编辑器不会因为预览渲染而改写标题、列表、链接或强调符号。

Markdown 语法高亮是独立的显示功能。开启时只改变 Markdown 语法类别和符号的颜色，不改变字符、字体形状、保存文本或预览结果；关闭时编辑区显示普通文本。

## 预览内容

预览支持标题、段落、列表、链接、图片、表格、代码块和数学公式等 Markdown 内容。代码块会按照语言标记显示对应的代码块样式，数学公式使用 LaTeX 规则渲染。

### SpringTree 思维导图

语言标记为 `springtree` 的代码块会被渲染成思维导图，而不是普通代码块。该格式基于 Markdown 无序列表，主要用于回忆书的“思维导图”模式输出，也可以在任何笔记中手动编写。

#### 语法规则

- 代码块语言标记写为 `springtree`。
- 每一行表示一个节点，节点以 `-` 开头。
- 使用缩进表示层级关系：缩进越多的节点越深，上级节点为父节点，下级节点为子节点。
- 节点文本为纯文本，可包含普通文字、数字、符号等；不支持嵌套 Markdown 样式。
- 同一层级的节点按出现顺序从左到右或从上到下排列。

#### 示例

````markdown
```springtree
- 项目总览
  - 前端开发
    - 完成登录页面
    - 优化首页加载速度
  - 后端开发
    - 设计用户表结构
    - 接入 OAuth 登录
  - 下周计划
    - 联调接口
    - 补充单元测试
```
````

上述内容会渲染为一棵以“项目总览”为中心、向外展开的思维导图。

#### 交互方式

渲染后的思维导图支持以下操作：

- **平移**：在导图画布上按住鼠标左键拖动，或在触摸屏上拖动。
- **缩放**：使用鼠标滚轮缩放，或点击右下角的“放大”“缩小”按钮；缩放范围限制在 0.2× 到 3×。
- **适应全图**：点击“适应全图”按钮，画布会自动居中并缩放到完整显示整个导图。
- **全屏查看**：点击“全屏查看”按钮，导图会以全屏弹窗打开；点击“退出全屏”或按 `Esc` 关闭。
- **复制源码**：点击导图顶部的“复制”按钮，可复制原始的 `springtree` 文本。

导图节点的文字不可选中，避免与平移手势冲突。

#### 生长动画

- 在回忆书对话等流式生成场景中，导图节点会随文字输出逐个“生长”出现，带淡入缩放动画。
- 为保证流畅度，当一次更新一次性新增超过 96 个节点时（例如打开一篇已经写好的大型导图），该批节点会直接显示，不播放生长动画。

#### 节点数量上限

springtree 导图有两级数量限制：

- **解析上限**：任何导图在解析时最多保留 300 个节点，超出的行直接丢弃，对便签、全屏视图和回忆书同样生效。单个节点的文字超过 120 个字符时会被截断并显示省略号。
- **内联渲染上限**：为保证大型导图的打开与切换速度，笔记的内联视图（预览、分栏）最多渲染 120 个节点。节点按层级优先保留：先显示根节点和浅层分支，超出上限的深层分支整体不显示。导图被截断时，顶部会显示“+N”标记，N 为未显示的节点数量，鼠标悬停在该标记上可查看说明；点击“全屏查看”可打开完整导图，全屏视图不受内联上限影响。

回忆书页面没有内联渲染上限，对话中的导图按解析结果完整渲染（即最多 300 个节点）。

预览区域支持文本选择和滚动。Markdown 链接可以打开对应链接，图片按照笔记所在目录和数据目录中的引用路径查找并显示。

## 图片引用

通过笔记本插入的图片会在 Markdown 中保存为图片链接，预览时根据当前笔记路径解析相对路径。删除 Markdown 图片链接只会改变正文引用，不会自动删除数据目录中的图片文件；图片文件的清理由存储管理页面处理。

## 空内容与异常

当前 Markdown 为空时，预览区域显示空状态提示，不会生成虚假的正文。图片路径无效时，正文中的链接仍然保留，但预览无法显示对应图片。无法识别的 Markdown 结构会按可解析的普通文本或基础结构显示，不会删除原始源码。
